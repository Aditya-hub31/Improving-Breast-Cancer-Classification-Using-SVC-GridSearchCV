# Improving Breast Cancer Classification Using SVC & GridSearchCV

A machine learning project focused on classifying breast tumors as **benign or malignant** using a **Support Vector Classifier (SVC)** with **GridSearchCV** for hyperparameter tuning.

## Project Overview

This project was developed as a B.Tech major project to explore the application of machine learning techniques to breast cancer classification.

The system uses the Wisconsin Breast Cancer Diagnostic (WBCD) dataset and applies data preprocessing, exploratory analysis, Support Vector Classification, and 5-fold cross-validation with GridSearchCV to optimize model hyperparameters.

## Approach

The project follows these major steps:

1. Dataset loading and preprocessing
2. Feature selection
3. Exploratory Data Analysis
4. Feature standardization
5. Train-test split
6. Support Vector Classifier implementation
7. Hyperparameter tuning using GridSearchCV
8. Model evaluation
9. Saving the trained model

## Model

The primary model used is Support Vector Classifier (SVC).

GridSearchCV is used to search across different combinations of:

* `C`
* `kernel`
* `gamma`

The model is evaluated using **5-fold cross-validation**.
